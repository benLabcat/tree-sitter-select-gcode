# Tree-Sitter Select GCode

A Tree-Sitter grammar for the ISG CNC programming language subset used by
Select 4 machines, including Select-specific laser, gas, ramp, shape, and
process-parameter macros.

## Scope

The grammar follows two complementary references:

1. The ISG CNC programming manual as the base language specification.
2. Real Select 4 CNC programs and command documentation for the implemented
   subset and machine-specific extensions.

The project prioritises syntax highlighting and robust parsing of real Select
programs. Broader ISG compatibility will be added incrementally.
