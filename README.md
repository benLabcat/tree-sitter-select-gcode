# Tree-Sitter Select GCode

Tree-Sitter parser and Zed extension for Bystronic / Coherent Select GCode programs.

## Goals

- Accurate parsing of Select GCode
- Syntax highlighting
- Symbol outline
- Future LSP support
- Zed integration

## Project Status

Early development.
